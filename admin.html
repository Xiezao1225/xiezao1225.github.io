当前 provider：—

展开：Supabase 配置步骤 + 建表 SQL
  1. 建项目 —— 注册 supabase.com → New project。 数据库密码单独设一个，别和登录密码混用。
  2. 跑 SQL —— SQL Editor → New query，把下面整段粘进去 Run。 策略里的邮箱必须和你接下来要用来登录的邮箱完全一致，这是"只有你能编辑"的唯一保障。
  3. 建账号 —— Authentication → Users → Add user，邮箱同上， 务必勾 Auto Confirm User（QQ 邮箱收验证信常延迟或被丢进垃圾箱，勾了直接绕开）。
  4. 抄两个值 —— Project Settings → API： Project URL 只到主域名为止（不要带 /rest/v1）， 再复制 anon public / Publishable key。 ⚠️ 绝对不要复制 service_role / Secret key，那个能绕过所有策略。
  5. 填进配置 —— 打开 assets/js/status.config.js， 把 provider 改成 'supabase'，填上 url 和 anonKey， 再把 owner.email 填成同一个邮箱。刷新本页即可登录。
  6. 想要秒级推送？（可选） —— 新版 sb_publishable_ key 不是 JWT， 在 REST 和登录上完全没问题，但 Realtime 的 WebSocket 对它兼容不好 （官方 issue supabase/realtime#1561），控制台会报 WebSocket connection ... failed。 这种情况页面会自动降级成 20 秒轮询，功能一样完整。 要恢复实时推送，去 Settings → API Keys → Legacy API keys 复制 anon 那串 eyJ...，填进配置里的 supabase.realtimeKey。
